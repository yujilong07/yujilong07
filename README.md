## About

I'm a **backend developer and AI engineer** studying Computer Science with a specialization in Artificial Intelligence at **NURE (Kharkiv National University of Radio Electronics)**, currently living and studying remotely from **Rome, Italy**.

I build backend systems and AI-powered applications — from async task pipelines with Celery and Redis, to LLM-integrated products with streaming responses, to Dockerized multi-service architectures. My work ranges from a production AI document-generation platform to hackathon-built contract analysis tools, alongside hands-on cloud infrastructure work (AWS, CI/CD) on a live team project.

Outside of backend work, I tinker with embedded hardware (ESP32) and I'm currently designing a C++ system-level application from the ground up.

**Open to:** Junior Backend Developer roles · AI/ML Engineer opportunities · Remote & Rome-based positions
